# Капибулка — булки дня

Локальная одностраничная витрина мини-пекарни «Капибулка». Посетитель знакомится с булкой дня «Коричная капибара» и выбирает её; страница показывает подтверждение без отправки данных.

## Как открыть

Откройте `index.html` в браузере двойным щелчком или через меню браузера «Открыть файл». Сервер, установка и подключение к интернету не нужны.

Состав и границы проекта описаны в [spec.md](./spec.md), порядок работ — в [PLAN.md](./PLAN.md).
