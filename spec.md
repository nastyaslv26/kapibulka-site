# Спецификация

## Назначение и сценарий

Одна локальная страница «булки дня» для мини-пекарни «Капибулка». Посетитель:
1. Видит название и короткое обещание.
2. Читает карточку булки дня «Коричная капибара».
3. Нажимает «Выбрать булку дня» и видит локальное подтверждение выбора.
4. В отдельной интерактивной итерации сбрасывает выбор и возвращается к исходному состоянию.

## Состав страницы

- Шапка с названием пекарни.
- Первый экран с коротким обещанием.
- Заметная карточка предложения «Коричная капибара», кнопка выбора и область подтверждения.
- Три коротких шага, объясняющих сценарий: посмотреть, выбрать, получить подтверждение.

## Визуальное направление

Тёплый кремовый фон, тёмно-зелёный основной цвет, коралловый акцент, крупная типографика и заметная карточка предложения. Интерфейс должен оставаться читаемым и на узком экране.

## Наблюдаемые критерии готовности

- При локальном открытии `index.html` отображаются шапка, обещание, карточка булки дня и три шага.
- В карточке указано название «Коричная капибара» и видна кнопка «Выбрать булку дня».
- Нажатие на кнопку показывает понятное подтверждение на этой же странице, без перехода и сетевого обмена.
- В отдельной последующей итерации сброс возвращает страницу к исходному состоянию.
- Все ресурсы и логика находятся в одном файле; страница работает без установки и интернета.

## Границы

Только один самодостаточный `index.html` со встроенными HTML, CSS и простым JavaScript. Без фреймворков, серверной части, базы данных, внешних зависимостей, сетевых запросов, реальных данных и секретов. Не добавлять функции вне описанного сценария; сброс выбора реализовать только на предусмотренном третьем шаге плана.
